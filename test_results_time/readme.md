# Test Results

This folder contains the test results for the two use cases.

There are two folders, one for each use case. Inside each folder, there are two files:

## Files

- `average_data_<use_case>.csv` 
  Contains the results, used in our work, obtained by computing the average values from 10 executions of the script for each DSL.

- `raw_data_10_run_<use_case>.csv`  
  Contains the raw results from 10 executions of the script for each DSL.
